# Plant Disease Classification Using Transfer Learning and CNNs

A deep learning project that classifies plant leaf diseases using
Convolutional Neural Networks (CNNs) and transfer learning.

## Project Objectives

- Explore and prepare a plant leaf image dataset.
- Train an image classification model using MobileNetV2.
- Evaluate model performance using appropriate classification metrics.
- Build an interactive prediction application using Streamlit.

## Technology Stack

- Python 3.12
- TensorFlow / Keras
- Scikit-learn
- Matplotlib and Seaborn
- Pillow
- Streamlit

## Project Status

In development.

## Planned Features

- Image preprocessing and data exploration
- Transfer learning model training
- Model evaluation and confusion matrix
- Image upload and prediction interface
- Reproducible setup instructions

## Dataset

The project plans to use the PlantVillage dataset.
Dataset source: https://github.com/spMohanty/PlantVillage-Dataset

## Disclaimer

Predictions are experimental and should not be treated as
professional agricultural diagnoses.
